# Gallery Images

Place past event photos here.

## Recommended Specs
- **Format:** JPEG, PNG, or WebP
- **Resolution:** At least 800×600
- **Naming:** Any name works (e.g., `event-1.jpg`, `expo-2024.png`)

These images will be displayed in the 3D Tunnel Gallery section.
Update the `TunnelGallery.tsx` component to reference your actual image paths.
