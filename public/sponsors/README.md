# Sponsor Logos

Place sponsor/partner logos here.

## Recommended Specs
- **Format:** PNG (transparent background) or SVG
- **Resolution:** At least 300×150
- **Naming:** Use brand name (e.g., `mojo.png`, `bkash.png`, `grameenphone.svg`)

Update the `Sponsors.tsx` component to use actual image paths instead of text placeholders.

Example:
```tsx
// In Sponsors.tsx, replace the text placeholder with:
<img src="/sponsors/mojo.png" alt="Mojo" className="h-12 object-contain" />
```
